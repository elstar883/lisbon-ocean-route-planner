# QA-чек-лист «Маршрут — Лиссабон и океан»

## 1. Автоматическая проверка

```bash
node scripts/validate.mjs
node --check app/app.js
```

Ожидаемый результат:

```text
OK: 7 дней, 17 событий «Спокойно», 28 событий «Насыщенно»,
4 бронирования, 10 задач чек-листа и 6 категорий бюджета.
```

CI повторяет проверку на Node.js 18, 20 и 22.

## 2. Быстрый запуск

```bash
make serve
```

Откройте <http://127.0.0.1:8080>. Проверка выполняется в Chrome или Chromium.

## 3. Десктоп 1440 px

- [ ] Обложка показывает «Лиссабон и океан», «12–18 сентября», «7 дней» и
      обратный отсчёт.
- [ ] Видны 7 вкладок дней и три события первого дня.
- [ ] Бюджет показывает `162 000 ₽`, остаток `18 000 ₽` и прогресс `90 %`.
- [ ] Четыре бронирования: одно подтверждено, три ожидают.
- [ ] Чек-лист показывает `0/10`.
- [ ] Нет горизонтальной прокрутки.
- [ ] Двухколоночная компоновка: маршрут слева, чек-лист справа.

## 4. Темп

- [ ] Переключение на «Насыщенно» меняет подсказку, стоимость дня, прогноз,
      бюджет и количество событий.
- [ ] Первый день в режиме «Насыщенно» содержит 4 события.
- [ ] Переключение обратно на «Спокойно» возвращает 3 события и `162 000 ₽`.
- [ ] Выбранный темп сохраняется после перезагрузки.

## 5. Дни маршрута

- [ ] Клик по «День 3 • Синтра» обновляет город, дату и список событий без
      перезагрузки.
- [ ] Мобильный блок «Сегодня» синхронно показывает Синтру.
- [ ] Клик по другому дню обновляет и список, и мобильный блок.

## 6. Бронирования

- [ ] Кнопка «Подтвердить» меняет статус карточки на «подтверждено».
- [ ] Появляется уведомление «Бронирование подтверждено».
- [ ] Статус связанного события в маршруте меняется на «подтверждено».
- [ ] После перезагрузки подтверждение сохраняется.
- [ ] После «Сбросить учебные данные» остаётся только одно исходное
      подтверждение.

## 7. Чек-лист

- [ ] Отметка задачи увеличивает прогресс.
- [ ] Следующая задача в мобильном блоке меняется.
- [ ] После перезагрузки отметки сохраняются.
- [ ] Кнопка сброса возвращает `0/10`.
- [ ] Сброс также возвращает темп «Спокойно» и первый день.

## 8. Демо состояний

- [ ] «Загрузка» показывает скелетоны и скрывает список.
- [ ] «Ошибка» показывает сообщение и кнопку «Повторить».
- [ ] «Повторить» возвращает обычный список.
- [ ] «Пустой день» показывает объяснение и подсказку.
- [ ] «Готово» возвращает `success`.
- [ ] Панель сворачивается и разворачивается.
