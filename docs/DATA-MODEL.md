# Модель данных «Маршрут — Лиссабон и океан»

Все данные демонстрационные. Реальные рейсы, отели, адреса и платежи не
используются.

## 1. Поездка

```js
const TRIP = {
  title: "Лиссабон и океан",
  dates: { start: "2025-09-12", end: "2025-09-18" },
  daysCount: 7,
  route: ["Лиссабон", "Кашкайш", "Синтра", "Эрисейра", "океан", "Лиссабон"],
  budgetTotal: 180000
};
```

- `dates.start` и `dates.end` задают демонстрационный диапазон;
- год используется только для расчёта дат и обратного отсчёта;
- `daysCount` равен семи;
- `budgetTotal` равен 180 000 ₽.

## 2. Темп

```js
const PACE_CONFIG = {
  calm: {
    label: "Спокойно",
    hint: "Больше времени на отдых и неспешные прогулки.",
    costMultiplier: 0.9,
    forecastDelta: -10000
  },
  busy: {
    label: "Насыщенно",
    hint: "Максимум впечатлений: экскурсии и активности каждый день.",
    costMultiplier: 1.15,
    forecastDelta: 15000
  }
};
```

`costMultiplier` применяется к категориям бюджета, `forecastDelta` — к сумме
стоимости всех событий.

## 3. День и событие

```js
{
  id: 0,
  dayNum: 1,
  city: "Лиссабон",
  dateLabel: "12 сентября",
  events: [
    {
      id: "d0-c1",
      time: "10:00",
      title: "Прилёт в Лиссабон",
      category: "перелёт",
      cost: 22500,
      bookingRef: "b-flight"
    }
  ]
}
```

Поля события:

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | уникальный идентификатор в пределах набора |
| `time` | string | время в формате `HH:MM` |
| `title` | string | название события |
| `category` | string | перелёт, размещение, транспорт, экскурсия, питание, другое |
| `cost` | number | стоимость в рублях, `0` допустим |
| `bookingRef` | string \| null | ссылка на бронирование или `null` |

## 4. Наборы дней

`DAYS_BY_PACE.calm` — 17 событий:

| День | Город | Событий |
|---:|---|---:|
| 1 | Лиссабон | 3 |
| 2 | Кашкайш | 3 |
| 3 | Синтра | 2 |
| 4 | Эрисейра | 2 |
| 5 | океан | 2 |
| 6 | Лиссабон | 2 |
| 7 | Лиссабон | 3 |

`DAYS_BY_PACE.busy` — 28 событий, по 4 события в каждом дне.

Оба набора содержат одинаковые `id` дней и одинаковые города, но разные события,
время и стоимость.

## 5. Бронирование

```js
{
  id: "b-flight",
  type: "перелёт",
  title: "Перелёт Москва–Лиссабон",
  details: "Рейс демонстрационный",
  status: "не подтверждено"
}
```

- четыре бронирования: перелёт, отель, поезд/трансфер, экскурсия;
- допустимые статусы: `подтверждено`, `не подтверждено`;
- подтверждение меняет статус и сохраняется в `localStorage`;
- события ссылаются на бронирования через `bookingRef`.

## 6. Чек-лист

```js
const CHECKLIST_INITIAL = {
  documents: [{ id: "c1", text: "Паспорт", checked: false }],
  money: [...],
  things: [...],
  health: [...]
};
```

- 10 задач;
- категории: `documents`, `money`, `things`, `health`;
- каждая задача содержит `id`, `text`, `checked`;
- прогресс считается по всем категориям.

## 7. Бюджет

```js
const BUDGET_CATEGORIES_BASE = [
  { key: "flight", label: "Перелёт", amount: 25000 },
  { key: "hotel", label: "Отель", amount: 80000 },
  { key: "train", label: "Транспорт", amount: 15000 },
  { key: "excursion", label: "Экскурсии", amount: 20000 },
  { key: "food", label: "Питание", amount: 25000 },
  { key: "other", label: "Прочее", amount: 15000 }
];
```

Сумма базы — 180 000 ₽. Для выбранного темпа каждая категория умножается на
`costMultiplier` и округляется.

## 8. `localStorage`

| Ключ | Формат | Назначение |
|---|---|---|
| `routePlanner.bookings` | JSON-массив | бронирования |
| `routePlanner.checklist` | JSON-объект | чек-лист |
| `routePlanner.pace` | `calm` или `busy` | темп |

Чтение и запись обёрнуты в `try/catch`. При повреждённых данных используются
исходные значения. Кнопка сброса записывает исходные данные обратно.

## 9. Инварианты

- в каждом наборе ровно 7 дней;
- `dayNum` идёт от 1 до 7;
- события ссылаются только на существующие бронирования;
- `cost` неотрицателен;
- прогресс бюджета ограничен диапазоном 0–100 %;
- прогресс чек-листа равен `checked / total`;
- мобильный экран всегда показывает выбранный день;
- приложение не делает сетевых запросов и не использует реальные данные.
