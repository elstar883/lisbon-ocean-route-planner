# Критерии готовности «Маршрут — Лиссабон и океан»

## 1. Основные блоки

- [ ] Обложка показывает название поездки, даты, количество дней, обратный
      отсчёт и декоративную линию маршрута.
- [ ] Переключатель темпа меняет события выбранного дня, стоимость дня,
      подсказку и общий прогноз расходов.
- [ ] Маршрут по дням показывает город, дату, время, название события,
      категорию, стоимость и статус бронирования.
- [ ] Бюджет показывает общий бюджет, запланированную сумму, остаток, прогресс и
      категории расходов.
- [ ] Четыре карточки бронирований отображают статус и позволяют подтвердить
      неподтверждённое бронирование.
- [ ] После подтверждения появляется уведомление.
- [ ] Чек-лист содержит категории «Документы», «Деньги», «Вещи» и «Здоровье».
- [ ] Отметки чек-листа и бронирования сохраняются после перезагрузки через
      `localStorage`.
- [ ] Кнопка «Сбросить учебные данные» возвращает исходное состояние.

## 2. Мобильный режим

- [ ] На ширине 390 px первым блоком показывается «Сегодня».
- [ ] Видны текущий день, ближайшее событие, город, время, статус бронирования и
      следующая задача чек-листа.
- [ ] Нижняя навигация содержит «Сегодня», «Маршрут», «Бюджет», «Подготовка» и
      прокручивает к соответствующему разделу.

## 3. Состояния интерфейса

- [ ] `loading` показывает скелетоны.
- [ ] `error` показывает понятное сообщение и кнопку «Повторить».
- [ ] `empty` объясняет отсутствие событий в выбранном дне.
- [ ] `success` показывает обычный список событий.
- [ ] Все четыре состояния доступны из панели «Демо состояний».

## 4. Адаптивность

- [ ] Нет горизонтальной прокрутки на 1440, 768 и 390 px.
- [ ] Нет наложения элементов и слишком мелкого текста.
- [ ] На 1440 px работает двухколоночная компоновка.
- [ ] На 768 px работает компактная планшетная компоновка.

## 5. Технические ограничения

- [ ] Используются только HTML, CSS и JavaScript.
- [ ] Нет React, Vue и других фреймворков.
- [ ] Нет npm-зависимостей, сборщиков, внешних библиотек и CDN.
- [ ] Нет базы данных, авторизации, внешних API и загрузки данных из интернета.
- [ ] Приложение работает после обычного открытия `index.html` в браузере.
- [ ] Структура приложения: `app/index.html`, `app/styles.css`, `app/app.js`.

## 6. Качество и публикация

- [ ] Все даты, суммы, адреса и бронирования помечены как демонстрационные.
- [ ] В репозитории нет `.env`, токенов, `*.zip`, `*.pdf`, `.DS_Store` и
      браузерных артефактов.
- [ ] `node scripts/validate.mjs` проходит локально и в CI.
- [ ] README содержит быстрый старт, скриншоты, данные и ограничения.
- [ ] Ветки и коммиты оформлены по правилам `CONTRIBUTING.md`.
